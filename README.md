# Hi, I'm Dan 👋

I'm a software engineer and computer scientist with a PhD in programming languages and formal methods.

I've spent the last decade working on compilers, static analysis, functional programming, and audio software. 
I enjoy exploring interesting ideas and turning them into working software.

I'm also an electronic music producer, which occasionally leads to music-related coding experiments.

## Selected projects

- **[DJ Buddy](https://github.com/dfilaretti/dj-buddy)** — A DJ playlist builder written in Haskell. [Read the article](https://dfilaretti.github.io/dj-buddy/).
- **[KPHP](https://github.com/dfilaretti/KPHP)** — Executable formal semantics of PHP, developed as part of my PhD research.
- **[WeirdDrums](https://github.com/dfilaretti/WeirdDrums)** — An open-source drum synthesizer plugin written in C++.
- **Static analyzer (coming soon)** — A small implementation revisiting ideas from my PhD research.
